# Stream UI Experiment

A UI-focused web application inspired by modern streaming platforms, built to explore layout systems, component design, and interactive user experiences.

This project started as a creative exploration of how different content styles and user personas can be presented through a unified interface, while maintaining clarity and visual consistency.

---

## Overview

The application is structured around multiple content perspectives, each with its own tone and visual identity. Instead of treating them as separate apps, the goal was to design a system where different sections coexist within a shared layout and design language.

Key focus areas:
- Designing scalable UI layouts
- Managing multiple visual themes within one application
- Creating consistent navigation across distinct sections
- Improving user experience through structure and spacing

---

## Tech Stack

- **Frontend:** React (Vite)
- **Styling:** Tailwind CSS
- **Routing:** React Router
- **Deployment:** GitHub Pages
- **Design System:** Custom color themes, reusable components, and consistent layout structure

---

## Features

- Responsive layout across different screen sizes  
- Component-based architecture for reusability  
- Theme variations for different sections  
- Structured navigation across multiple content types  
- Data-driven content rendering  
- Smooth hover interactions and transitions
